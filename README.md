## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/EqualizerPrime.git`
2. `cd EqualizerPrime`
3. Install in editable mode: `pip install -e .`

## Configuration

EqualizerPrime is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
